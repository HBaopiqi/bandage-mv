## 作品简介

《绷带》写的是一个人在成长途中，学会与焦虑、失败和未愈合的伤口相处。凌晨的街、没回的消息、走得比自己更快的人，都曾让方向变得模糊；但那些一圈又一圈缠上的绷带，是为了提醒自己曾经怎样一路走到这里。路还很长，答案可以晚一点出现，只要还愿意向前走，就还没有终点。

## 网页 MV

这是一套随歌曲时间轴展开的手绘拼贴文字动画。画面围绕凌晨街道、背包、旧帆布鞋、心脏、绷带与远方的路展开，并根据歌词情绪改变字体、构图、色彩和运动节奏。

- 完整歌曲与逐句歌词时间轴
- 手绘、蜡笔、撕纸拼贴视觉
- 加载首页与播放进度控制
- 全屏观看、章节跳转和画面保存
- 桌面端与手机横屏适配

## 项目结构

```text
dist/
├─ index.html        # 网站入口
├─ styles.css        # 页面与移动端样式
├─ loading.js        # 加载首页逻辑
├─ player.js         # 播放器与时间轴驱动
├─ art.js            # 动画场景绘制
├─ collage.js        # 拼贴素材调度
└─ assets/           # 音频、歌词、字体与拼贴素材
```

## 本地运行

在仓库根目录启动任意静态文件服务器，并将网站根目录指向 `dist`。例如：

```bash
python -m http.server 8768 --directory dist
```

然后访问 `http://127.0.0.1:8768/`。浏览器需要允许音频播放；手机横屏观看时画面更舒展。
