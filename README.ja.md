## 作品について

『绷带』（包帯）は、成長の途中で不安や失敗、まだ癒えていない傷と向き合っていく一人の姿を描いた作品です。夜明け前の街、返事のないメッセージ、自分より速く進む人たち。そのどれもが、進む方向を見失わせることがあります。

このブラウザー MV は歌詞を絵コンテに見立て、ドラムの拍と余白で動きのリズムを作っています。リュック、履き古したキャンバスシューズ、携帯電話、心臓、包帯が、ちぎり紙やクレヨン、手描きの線の中に繰り返し登場します。文字は字幕であるだけでなく、道や椅子、ポケット、傷にも変わります。道のりは長く、答えが見つかるのは少し先でもいい。歩き続ける気持ちがあるかぎり、旅はまだ終わりません。

楽曲と画面内の歌詞は中国語です。

## ビジュアルとアニメーション

![『绷带』MV の主要シーン](docs/mv-keyframes.png)

- 歌詞を音声全体のタイムラインに一行ずつ同期し、曲の区切りや強拍に合わせて動きを変化
- 手描き、クレヨン、ちぎり紙、コラージュを楽曲全体に使用
- 歌詞の感情に応じて、文字サイズ、字間、構図、移動方向が変化
- ロード画面、セクション選択、シーク、静止画保存、全画面再生
- PC とスマートフォンの横向き表示に対応し、タッチで再生操作が可能

## 技術構成

HTML、CSS、JavaScript のみで構築しており、フロントエンドフレームワークは使用していません。Canvas で文字、図形、コラージュ素材をフレームごとに描画します。音声の再生時刻を唯一の基準として、歌詞、トランジション、シーンのアニメーションを制御しています。フォント、歌詞のタイミングデータ、ビジュアル素材はリポジトリに含まれています。

```text
dist/
├─ index.html              エントリーページとプレーヤーの構造
├─ styles.css              ページ、ロード画面、モバイル向けレイアウト
├─ loading.js              素材の事前読み込みと入場処理
├─ player.js               音声操作とタイムライン制御
├─ art.js                  シーンごとのアニメーションと文字組み
├─ collage.js              コラージュ素材の制御
└─ assets/                 音声、歌詞、フォント、ビジュアル素材
```

## ローカルで実行

```bash
python -m http.server 8768 --directory dist
```

<http://127.0.0.1:8768/> を開くと視聴できます。バックエンドアプリケーションや依存パッケージのインストールは不要です。
